## 1. Общее описание и архитектура

Torquemada 228 AGI (внутреннее имя — **W420**) — десктопное приложение для самообслуживаемого мониторинга и защиты хостов, с ИИ-слоем («Madre Torquemada») и оконным интерфейсом в стиле операционной системы.

### Состав

| Компонент | Путь | Назначение |
|---|---|---|
| Tauri-приложение | `app/src-tauri/` | Нативное окно, 300+ команд Rust-бэкенда |
| Тонкий клиент | `app/dist/` | HTML/CSS/JS: рабочий стол, окна, приложения, i18n |
| Ядро | `crates/w420-core/` | Firewall, хосты, SIEM, здоровье, БД (SQLite) |
| ИИ-слой | `crates/w420-ai/` | Провайдеры, ротация ключей, шифрование ключей |
| TTS-сервер | `tts-server/` | Синтез/распознавание речи |
| Sidecar-бинарники | `sing-box`, `trivy`, `gitleaks`, `nmap` | Внешние утилиты, вызываются из Rust |

### Хранение данных

Все данные — в SQLite-базе профиля приложения (`~/.local/share/*/w420/` или каталог, заданный `settings.json`): события, инциденты, хосты, правила, реестр, аудит, статистика ключей. Ключи API провайдеров хранятся **зашифрованными** (AES-256-GCM), во фронтенд отдаётся только маска вида `…abcd`.

### Маркировка зрелости в UI

- `LIVE` — функционал реализован и работает с реальными данными системы;
- `SIM` — симуляция/демонстрация (например, минтинг токенов, часть радио-контента);
- `WIP` — задумано и частично реализовано, в разработке (например, сетевой режим кошелька).

Это осознанная прозрачность, а не дефект: система не выдаёт незавершённое за готовое.

## 2. Установка

### 2.1 Однокомандная установка

```bash
git clone https://github.com/PerfectFriend/Torquemada-AGI-OS-420.git
cd Torquemada-AGI-OS-420
bash SETUP.sh
```

Флаги `SETUP.sh`:

| Флаг | Действие |
|---|---|
| `--from-release` | Взять готовые бинарники вместо сборки из исходников |
| `--skip-root` | Пропустить root-настройку (firewall/сервисы) — для запуска без sudo |
| `--help` | Показать справку |

Скрипт: проверяет зависимости (`git`, `curl`, `jq`, `sudo`, `build-essential`, `nodejs`, `cargo`), подсказывает команды установки для Debian/Ubuntu (`apt-get`) и Fedora/RHEL (`dnf`), собирает проект, раскладывает бинарник и создаёт ярлык на рабочем столе.

### 2.2 Ручная сборка

```bash
source ~/build/env.sh          # путь к Rust/Node из ~/build (опционально)
cargo build --release          # весь workspace
cargo test --lib               # тесты ядра и ИИ-слоя
```

Бинарник: `target/release/w420` (или `$CARGO_TARGET_DIR/release/w420`).

### 2.3 Root-настройка (отдельный шаг, запускается вами, не через sudo-в чате)

```bash
sudo -S -p '' bash scripts/root_setup.sh
```

Что делает `root_setup.sh`:

- создаёт/обновляет узкие правила `sudoers` (см. §16);
- устанавливает helper `/usr/local/sbin/w420-apt-install` — единственный разрешённый путь установки пакетов, с валидацией имён (`^[a-z0-9][a-z0-9.+-]{0,63}$`, 1–50 аргументов);
- ставит `setcap` на бинарники, которым нужны сырые сокеты (`cap_net_admin`, `cap_net_raw`) — чтобы не требовался NOPASSWD;
- настраивает WireGuard-конфиг `/etc/wireguard/w420wg.conf`.

Пароль sudo в чат/логи не передаётся: скрипт запускается вручную из терминала.

### 2.4 Зависимости во время работы

| Зависимость | Нужна для | Если отсутствует |
|---|---|---|
| `nft` | firewall (default-deny) | раздел Firewall отдаёт ошибку, остальное работает |
| `iproute2`, `wireguard-tools` | VPN-сервер, peer'ы | VPN-команды возвращают «tool not found» |
| `nmap` | сканер сети и портов | скан недоступен, ручной ввод результатов работает |
| `trivy`, `gitleaks` | CVE- и secret-сканирование | кнопки отчёта вернут «not installed» |
| `pkcs11-tool` (opensc) | Smart-Card (PKCS#11) | раздел покажет подсказку `apt install opensc` |
| `sing-box` (sidecar) | VPN-туннели | часть VPN-операций недоступна |
| `tor` | анонимизация | `tor_start` вернёт ошибку |

## 3. Запуск и обновление

### 3.1 Запуск с рабочего стола

Ярлык `~/.local/share/applications/w420.desktop`:

```
Exec=/home/thomas/TorquemadaAGI/launch.sh
```

`launch.sh` ищет бинарник по порядку и запускает первый найденный:

1. `$W420_TARGET_DIR/release/w420` (по умолчанию `~/build/cache/cargo-target-w420/release/w420` — выделенный кэш, чтобы сборка других проектов не сносила бинарь);
2. `~/build/cache/cargo-target/release/w420` (общий кэш);
3. `./w420` рядом с репозиторием;
4. `app/src-tauri/target/release/w420`.

### 3.2 Ручной запуск

```bash
~/TorquemadaAGI/launch.sh
# или напрямую
~/build/cache/cargo-target-w420/release/w420
```

### 3.3 Обновление до свежей версии

```bash
cd ~/TorquemadaAGI
git pull
source ~/build/env.sh
cargo build --release
cp "$CARGO_TARGET_DIR/release/w420" ~/build/cache/cargo-target-w420/release/w420.new
mv -f ~/build/cache/cargo-target-w420/release/w420.new ~/build/cache/cargo-target-w420/release/w420
```

> Если приложение сейчас запущено, бинарник занят — поэтому используется схема «скопировать во временный файл → переименовать». На Linux работающий процесс продолжает использовать старый inode, а новый запуск берёт уже свежий файл.

### 3.4 Проверка, что всё живо

```bash
pgrep -af 'release/w420'            # процесс запущен?
ls -la ~/build/cache/cargo-target-w420/release/w420
md5sum ~/build/cache/cargo-target-w420/release/w420 \
       ~/build/cache/cargo-target/release/w420   # совпадение = бинарник свежий
```

## 4. Режимы интерфейса: DESKTOP и CLASSIC

Система стартует в режиме **DESKTOP** — как настоящая ОС: пустой фон, иконки приложений слева, панель задач и трей снизу, окна с рамками и заголовками.

Классический «потоковый» интерфейс (шапка, сетка кнопок, боковые панели) вынесен в отдельное приложение **«🧩 Классика UI»**:

- иконка на рабочем столе (двойной клик) — переключает режим;
- пункт в меню **tools** (левый нижний угол) → «🧩 Классика UI ↔ Десктоп»;
- в режиме CLASSIC навигация переключает секции как в обычном веб-интерфейсе, а не открывает окна;
- повторное переключение возвращает чистый десктоп.

Панели, которые раньше «вылезали» прямо на фон (Запись сессий, Smart-Card, Реестр, Журнал событий, Менеджер файлов, Планировщик задач), теперь размещаются внутри окна **Network** (контейнер `#v-net-panels`) и на десктопе не появляются.

## 5. Рабочий стол: окна, панель задач, трей

### 5.1 Иконки

- Слева — иконки всех зарегистрированных приложений. **Двойной клик** — открыть окно, **одиночный** — выделить.
- Иконку можно **перетащить** мышью; позиция сохраняется в `localStorage` (ключ `w420-iconpos`) и восстанавливается при следующем запуске.
- **ПКМ по иконке**: «Открыть», «Закрыть окно», «Переименовать…» (показывает внутренний id приложения).
- **Drag & drop файлов на иконку** — показывает список перетащенных файлов (C3).
- Панели, случайно прибитые скриптами прямо к `body`, на десктопе скрываются (`body.w420-desktop > .panel {display:none}`).

### 5.2 Окна

| Действие | Как |
|---|---|
| Переместить | тянуть за заголовок |
| Изменить размер | тянуть за любой край/угол окна (8 направлений) |
| Развернуть / восстановить | кнопка `⛶` в заголовке или **двойной клик по заголовку** |
| Свернуть | кнопка `—` (окно уходит в панель задач) |
| Закрыть | кнопка `✕` |
| Snap (привязка) | перетащить к краю экрана — появляется зона предпросмотра: край → половина, угол → четверть, верх → разворот |
| Focus | клик по окну; порядок учитывается в Alt+Tab и панели задач |
| Контекстное меню | ПКМ по заголовку: свернуть/развернуть/закрыть, привязки, перенос на другой рабочий стол, новый рабочий стол |

Геометрия окон сохраняется (`localStorage`), поэтому после перезапуска окна возвращаются на свои места и на свой рабочий стол.

### 5.3 Панель задач (низ)

- Кнопки открытых окон; клик — свернуть/развернуть, ПКМ — меню окна.
- Переключатель рабочих столов, индикатор текущего стола, кнопка «Task view».
- Системный трей: часы, индикаторы (монитор/чат/AI), кнопка **tools** (левый нижний угол) — меню инструментов.

### 5.4 Меню tools (левая нижняя кнопка)

Содержит: список всех приложений, «Полный экран (Alt+Enter)», «🧩 Классика UI ↔ Десктоп», «Показать десктоп (Win+D)», «Свернуть все окна (Win+M)», «Каскад окон», Task view, запуск AI-чата, а также команды рабочих столов.

### 5.5 Task view, виртуальные столы, Alt+Tab

- **Task view (Win+Tab)** — сетка всех открытых окон, клик по окну фокусирует его.
- **Виртуальные столы**: новый стол (Win+Ctrl+D), закрыть стол (Win+Ctrl+W), переключение (Win+Ctrl+←/→), перенос окна на другой стол через контекстное меню.
- **Alt+Tab** — переключение между открытыми окнами; **Alt+1…9** — фокус на окно по номеру в списке активных.

### 5.6 Уведомления и панели

- Всплывающие уведомления (toast) в правом верхнем углу — результаты операций и ошибки.
- Центр уведомлений (колокольчик в трее) — накопившиеся сообщения.
- Календарь/дата по клику на часы.
- **Launcher (Win+K)** — поиск и запуск приложений по имени.

### 5.7 Полный экран

**Alt+Enter** разворачивает приложение на **весь десктоп целиком**: скрываются декорации окна (нативная команда `app_fullscreen_toggle` → `set_fullscreen(true)` + `set_decorations(false)`), а не просто растягивается одно окно. Повторное нажатие возвращает рамку и заголовок.

## 7. Приложения рабочего стола

Десять основных окон (иконки на десктопе) плюс deep-link пункты, открывающие нужную карточку внутри окна Network.

### 7.1 Terminal (`v-term`) — консоль W420

- Ввод команд в поле ввода, вывод в `#out`, история.
- Команды терминала: `help`, `status`, `scan`, `firewall`, `vpn`, `health`, `siem`, `ai`, `version` и др. (полный список — по `help`).
- Контекстное меню окна: очистка вывода.

### 7.2 QFS Vault (`v-vault`) — зашифрованное хранилище

- Создание/открытие/удаление секретов, шифрование по паролю, версии и история.
- PQCTag помечен `SIM` — постквантовая метка в интерфейсе демонстрационная.

### 7.3 Digital ID (`v-id`) — децентрализованная идентичность

- Генерация DID, подпись и проверка challenge, статус, список ключей.
- `WIP`: часть операций подписи помечена как в разработке.

### 7.4 AGI-Ω FM (`v-radio`) — радио

- Воспроизведение сценария/эпизода, дикторский голос (TTS), статус станции.
- Часть реплик — `SIM` (запасные реплики).

### 7.5 Audit Log (`v-audit`) — журнал аудита

- Хронология событий с фильтрами, выгрузка, подпись/проверка цепочки (session recording chain).

### 7.6 Wallet (`v-key`) — офлайн-кошелёк

- Создание/импорт ключей, подпись, баланс, seed-экспорт с подтверждением.
- Сетевой режим — `WIP`.

### 7.7 Crypto Wallet / Mint (`v-wallet`) — `SIM`

- Токены, mint, DEX — симуляция, реальная сеть не задействована.

### 7.8 Mind Map (`v-map`)

- Построение карты знаний (узлы/связи), AGI-анализ (`map_agi_status`), сохранение в БД.

### 7.9 AGI Assistant (`v-ai`) — `SIM` (частично)

- Чат с ИИ, запуск задач (`task_start/status/stop/approve`), быстрые сценарии (`BRIEF`), выбор модели и провайдера.

### 7.10 Network · Madre · SIEM · Health (`v-net`) — главный хаб

Самый насыщенный модуль, включает:

- **Обнаружение хостов**: подсеть → скан (`nmap`), список хостов, диффы между сканами.
- **Сканер уязвимостей**: цель/порты, VULN-СКАН, список уязвимостей, AI-отчёт.
- **SIEM**: ингест событий, корреляция, поиск, дашборд, AI-сводка, правила, инциденты (создание, смена статуса).
- **Health**: здоровье хостов по одному и по всем, health score, статус компонентов.
- **Madre (материнский ИИ)**: статус, режимы (`madre_mode_set`), белый список (`allow_add/remove/list`), применение вердикта, старт/стоп honeypot и watchdog, события, Helm-панель.
- **Firewall**: статус, список правил, добавить/удалить правило, изоляция хоста, логи.
- **VPN (WireGuard)**: инициализация сервера, добавление/отзыв peer'ов, список, старт/стоп сервера, статус, трафик.
- **Patch Management**: сканирование локального/всех хостов, список обновлений, установка патчей, план отката, статус, AI-оценка.
- **Web-сканер**: сканирование сети и целей, список уязвимостей веба, результаты, ack хоста, AI-отчёт, статус и выгрузка отчёта.
- **Traffic / IDS**: запуск/остановка захвата, алерты, статистика, блокировка и разблокировка IP, список заблокированных, синхронизация EVE-логов, AI-анализ трафика.
- **Файловый менеджер**: список/чтение/запись/chmod/удаление/поиск, удалённый вариант по хостам.
- **Журнал событий**: чтение, запрос, статистика, обрезка, удалённые логи.
- **Планировщик задач**: список процессов, kill, дерево процессов, автозапуск, удалённое выполнение.
- **Запись сессий**: старт/стоп, список записей, чтение.cast, рендер MP4, проверка цепочки (хэш-цепочка).
- **Smart-Card (PKCS#11)**: статус, слоты, токены, объекты, сертификаты, подпись.
- **Реестр**: локальный реестр w420 (kv + история), удалённый query/set/delete.
- **Health/SIEM deep-link**: пункты меню «Watchdog / Madre», «Health», «SIEM» открывают это же окно и подкручивают к нужной карточке.
- **ADVANCED COMMANDS** — карточка со всеми прочими командами бэкенда (см. §8).

## 8. Карточка ADVANCED COMMANDS

Внутри окна Network есть карточка **ADVANCED COMMANDS** — 54 кнопки, покрывающие команды, которые раньше существовали в бэкенде, но не имели кнопок в интерфейсе.

Как пользоваться:

1. Открыть окно Network → прокрутить до карточки ADVANCED.
2. Нажать нужную кнопку.
3. В появившемся системном диалоге ввести JSON-аргументы (например `{"hostId":"10.0.0.5"}`). Пустой ввод означает вызов без аргументов.
4. Результат команды показывается в выводе рядом.

Такой доступ удобен для отладки и тонкой настройки (SIEM-правила, EDR-агенты, PKI, sysops, update-каналы и т.д.), но требует знания точных имён аргументов — они совпадают с именами параметров Rust-команд (см. Приложение A).

## 16. Модель безопасности

### 16.1 Принципы

1. **Default-deny** — firewall по умолчанию блокирует всё, разрешено явно.
2. **Минимальные привилегии** — никаких широких `NOPASSWD`.
3. **Секреты не покидают бэкенд** — ключи API шифруются и маскируются, TTS-токен не форвардится в JS.
4. **Параметризованный SQL** — запросы к SQLite собираются через параметры, без конкатенации пользовательского ввода.
5. **Аудит действий** — значимые операции попадают в журнал аудита и журнал событий.

### 16.2 Шифрование ключей

- Алгоритм: **AES-256-GCM**, ключ шифрования выводится из мастер-пароля / системного хранилища.
- Реализация: `crates/w420-ai/src/encryption.rs` (`encrypt_api_key`, `decrypt_api_key`).
- В UI и логах — только маска `…abcd`.

### 16.3 Sudoers (после `root_setup.sh`)

Разрешено ровно:

| Правило | Зачем |
|---|---|
| `wg show *` | просмотр состояния WireGuard |
| `wg setconf w420wg /etc/wireguard/w420wg.conf` | применение конфига |
| 5 фиксированных `ip … w420wg` | up/down адреса и маршрутов интерфейса |
| `tee` только в `/etc/wireguard/w420wg.conf` | запись конфига (с фильтром содержимого) |
| `/usr/local/sbin/w420-apt-install` | установка пакетов с валидацией имён |

**Запрещено:** `nft`, `tcpdump`, `wg-quick`, полный `apt-get`/`apt`, `mkdir` без ограничений.
`nft` и `tcpdump` работают через `setcap` (`cap_net_admin`, `cap_net_raw`).

### 16.4 Что нужно для полноценной работы

- `sudo` с NOPASSWD-набором из §16.3 — иначе часть root-команд вернёт «permission denied»;
- `setcap` на бинарниках — иначе firewall и захват трафика не запустятся;
- для `StrictHostKeyChecking=no` в скриптах — осознанный компромисс автоматизации; для чувствительных хостов задавайте known_hosts вручную.

## 17. Диагностика и устранение неполадок

| Симптом | Причина | Решение |
|---|---|---|
| На десктопе «сетка» и карточки вместо иконок | скрипты прибивали панели к `body` | обновиться до текущей версии: панели в `#v-net-panels`; проверка: `document.querySelectorAll('body > .panel').length === 0` |
| Классический UI вместо десктопа | не загрузился `w420-desktop.css` | проверить `<link ... href="w420-desktop.css">` в `index.html` и что файл отдаётся сервером (HTTP 200) |
| `Text file busy` при копировании бинарника | приложение запущено | копировать во временный файл и `mv -f` (см. §3.3) |
| Порт 8421/8420 занят | старый процесс/сервер | `pkill -f 'http.server 8421'`, `lsof -i :8420` |
| `pkcs11-tool НЕ установлен` | нет opensc | `sudo apt install opensc` |
| `nft: command not found` / permission denied | нет бинарника или нет setcap | `sudo apt install nftables`, повторно выполнить `root_setup.sh` |
| Команда в ADVANCED возвращает ошибку аргументов | неверный JSON | сверить имена аргументов с Приложением A; для команд без аргументов оставить поле пустым |
| ИИ отвечает «no keys» / 402 | ключи не подтянуты или лимит | `ai_seed_keys_from_hermes`, проверить `ai_providers_status`, снять cooldown ключа (`ai_key_set_active`) |
| Приложение не запускается с иконки | бинарник не найден/не исполняем | `bash -n launch.sh`, `ls -la ~/build/cache/cargo-target-w420/release/w420`, `chmod +x` |
| Нет звука TTS | не поднят tts-сервер | `voice_status`, проверить порт 8420 и наличие sidecar |

### Полезные команды диагностики

```bash
pgrep -af 'release/w420'                   # процесс приложения
ss -ltnp | grep -E '8420|8421|4001|4010'   # слушающие порты
journalctl -u w420 -n 100 --no-pager       # systemd-лог (если включён сервис)
cargo test --lib                           # тесты ядра и ИИ
cargo clippy --workspace --all-targets     # статический анализ
```
