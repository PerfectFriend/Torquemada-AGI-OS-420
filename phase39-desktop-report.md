# Этап 39 — Desktop OS: интерфейс как у настоящей ОС

**Коммит:** `c4039ee` в `PerfectFriend/Torquemada-AGI-OS-420`.

## Что сделано
Новый слой поверх тонкого клиента — `app/dist/desktop.js` + `app/dist/w420-desktop.css` (матричный неоновый киберпанк, `--live:#00ff41`):

| Компонент | Поведение |
|---|---|
| **Окна** | Каждая секция `index.html` оборачивается в `.w420-window` с заголовком (иконка + имя + `—` свернуть + `✕` закрыть), drag за заголовок, z-index фокус, адаптивные размеры (≤72% × ≤70% экрана) |
| **Панель задач** (низ) | Слева кнопка **TOOLS** → грид всех 14 приложений; в центре иконки открытых окон (клик: фокус / свернуть / восстановить; правый клик: контекстное меню команд окна) |
| **Трей** (правый нижний угол) | 🖥 монитор (Health / Sysops / Network / Emergency), 💬 чат, 🧠 AI (Brief / Stop task / Lock keys / Full screen) — клик открывает выпадающее меню базовых команд |
| **Свернуть** | Окно уходит в фон — иконка в панели задач, состояние `minimized` |
| **Закрыть** | `onBeforeClose`/`onClose` модуля (реальная остановка работы) + окно скрывается, секция остаётся в DOM — повторное открытие мгновенное |
| **Alt+Enter** | Истинный fullscreen активного окна: заголовок и рамки скрыты, окно 100vw×100vh, `requestFullscreen()`; повторный Alt+Enter восстанавливает |
| **Alt+1..9** | Переключение между открытыми окнами |
