| `screenshots/04-settings-i18n.png` | Settings panel with language switch RU/EN/ES |
| `screenshots/05-themes.png` | Theme picker: matrix / cyberpunk / vangogh side by side |
| `screenshots/06-health.png` | Health dashboard panel |
| `screenshots/07-madre.png` | Madre panel: firewall rules, honeypot events |
| `screenshots/08-fullscreen.png` | Alt+Enter fullscreen (no decorations) |
