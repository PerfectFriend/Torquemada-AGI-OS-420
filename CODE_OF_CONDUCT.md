# Code of Conduct

## Наше обязательство
Мы хотим, чтобы участие в проекте Torquemada-AGI-OS-420 было свободным от домогательств для всех — независимо от возраста, телосложения, инвалидности, этнической принадлежности, гендерной идентичности, уровня опыта, национальности, внешности, расы, религии или сексуальной ориентации.

## Наши стандарты
Примеры поведения, которые приветствуются:
- Доброжелательность и терпение по отношению к новичкам
- Конструктивная критика кода, а не личности
- Признание ошибок и чужого вклада

Неприемлемо:
- Оскорбления, домогательства, дискриминационные высказывания
- Публикация чужих персональных данных без согласия
- Угрозы или поощрение насилия

## Область применения
Этот кодекс применяется во всех пространствах проекта: репозиторий, issues, PR, обсуждения, а также при представлении проекта офлайн.

## Enforcement
О случаях нарушения сообщайте владельцу репозитория через GitHub (приватный security-advisory для чувствительных случаев — см. SECURITY.md). Все жалобы рассматриваются конфиденциально. Нарушители могут получить предупреждение, временный или постоянный бан.

## Атрибуция
Адаптировано из [Contributor Covenant](https://www.contributor-covenant.org/), версия 2.1.
