# Contributing

Спасибо за интерес к проекту! Проект в стадии RC1, формат работы — фаза за фазой с отчётами.

## Как внести вклад

1. Форкните репозиторий, создайте ветку от `main`: `git checkout -b feat/my-feature`.
2. Соберите и прогоните тесты локально:
   ```bash
   cargo build --release
   cargo test --workspace          # app-тесты требуют локального окружения (~/.w420, sidecar-бинарники)
   cargo test -p w420-core -p w420-ai   # чистые юнит-тесты — проходят в CI
   ```
3. Коммитьте осмысленными сообщениями (RU или EN), пушьте в свой форк, открывайте PR в `main`.
4. PR проходит CI (`.github/workflows/ci.yml`): тесты крейтов + сборка + clippy.

## Стиль кода

- Rust: idiomatic, без паник в прод-путях без крайней нужды (`unwrap` допустим в тестах и при инвариантах).
- Комментарии и доки — **по-русски** (проект русскоязычный).
- SQL — только параметризованные запросы (rusqlite `params!`).
- Секреты не коммитить никогда: ключи только в зашифрованном виде в БД, в коде — только маски и фейки в тестах.
