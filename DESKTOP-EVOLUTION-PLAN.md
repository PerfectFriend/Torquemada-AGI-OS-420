# WINDOWS 420 · Desktop Evolution Plan
Дата: 2026-11-12 · Ветка: main · Десктоп-слой: `app/dist/desktop.js` + `w420-desktop.css` + тема в `index.html`

Цель: довести встроенный десктоп приложения до **полного набора функций стандартного десктопа ОС**,
сохранив матричную эстетику и zero-trust архитектуру W420.

### 1.2 Темы (8 штук)
matrix (default), amber, cyan, violet, red, light, **cyberpunk** (неон розовый/циан, Orbitron), **vangogh** («Звёздная ночь», золото на синем, рукописный Caveat, локальные woff2 latin+cyrillic).
Шрифты темы задаются переменными `--fh` (заголовки) / `--fb` (текст) на `:root[data-theme=...]`.

### 1.3 i18n
RU / EN / ES, 701 ключ в словаре, переключение в настройках, fallback на RU.

### 1.4 Что НЕТ (главные пробелы vs стандартный десктоп)
1. **Нет иконок на самом десктопе** (рабочий стол пустой — только окна поверх header+main).
2. **Нет виртуальных рабочих столов / рабочих пространств** (workspaces).
3. **Нет preview (превью) окна при наведении на иконку taskbar.**
4. **Нет «свернуть все» / «показать десктоп».**
5. **Нет прилипания окон (snap) к краям/половинам экрана** (tile left/right/quarters) и жеста Win+стрелки.
6. **Нет истории/каскада окон, нет «все окна списком» (task view).**
7. **Нет поиска по приложениям/командам** (глобальный launcher с фильтром, как Win+S / Spotlight).
8. **Нет часов/календаря в трее**, нет центра уведомлений (только toast, нет списка).
9. **Нет обоев (wallpaper)** — фон статический градиент темы; нет смены обоев и слайд-шоу.
10. **Нет персистентности раскладки окон** между сессиями (положения сбрасываются).
11. **Нет перетаскивания иконки в taskbar / группировки окон.**
12. **Нет контекстного меню самого десктопа** (ПКМ по фону: обновить, вставить, сменить обои, открыть терминал).
13. **Нет drag&drop файлов между окнами** и вообще файлового менеджера как окна.
14. **Нет системного монитора в трее** (CPU/RAM/ сеть inline, не только меню).
15. **Нет shade/roll-up окна** (двойной клик только maximize).
16. **Нет горячих клавиш сворачивания (Win+D show desktop, Win+M minimize all).**

## 2. Дорожная карта (фазы)

### Фаза A — «Ощущение настоящего десктопа» (быстрые победы)
- [x] **A1. Иконки приложений на десктопе**: grid в свободной области, dblclick открывает окно, drag по десктопу, ПКМ по иконке — контекстное меню.
- [x] **A2. Часы + дата в трее**, клик открывает календарь/уведомления.
- [x] **A3. Центр уведомлений**: список всех notify (сейчас только toast), badge-счётчик в трее.
- [x] **A4. Глобальный поиск/launcher**: поле в TOOLS-меню или Win+K — фильтр по приложениям и командам.
- [x] **A5. «Показать десктоп»**: кнопка в taskbar (крайняя правая полоска) или Win+D — сворачивает все окна; повторный клик восстанавливает.
- [x] **A6. Сворнуть все (Win+M)** и «каскад/тайл по порядку» в контекстном меню taskbar.

### Фаза B — Оконный менеджер уровня WM
- [x] **B1. Snap/tile**: drag окна к левому/правому краю → половина экрана; в верхний край → maximize; 4 угла → четверти. Win+←/→/↑/↓.
- [x] **B2. Preview на taskbar**: hover на иконку → миниатюра окна (scale transform), click переключает.
- [x] **B3. Task view**: Win+Tab — все открытые окна плиткой во весь десктоп, клик выбирает.
- [x] **B4. Виртуальные рабочие столы**: Win+Ctrl+←/→ переключение, на taskbar индикатор 1..N, окна привязаны к workspace; мини-map рабочих столов в task view.
- [x] **B5. Персистентность раскладки**: геометрия окон + workspace в `settings.json` (Tauri), восстановление при старте.
- [ ] **B6. Shade (roll-up)**: dblclick по заголовку = maximize (есть), отдельная кнопка/жест — сворачивает только тело окна (остаётся titlebar).

### Фаза C — Десктоп как поверхность
- [x] **C1. Обои**: выбор фона из набора (градиенты/паттерны/SVG), возможно загрузка своего изображения (через Tauri fs), хранение в settings; тема задаёт дефолтные обои.
- [x] **C2. Контекстное меню десктопа** (ПКМ по пустому фону): открыть терминал/AI, сменить обои, сменить тему, показать десктоп, обновить иконки.
- [x] **C3. Drag&drop на иконки десктопа/taskbar**: перетащить файл на иконку терминала/чат — «отправить» туда.

### Фаза D — Tray и система
- [x] **D1. Системный монитор inline в трее**: CPU/RAM/Net в одну строку (данные уже есть — `system_metrics`), обновление 1–2 с.
- [x] **D2. Tray-меню для монитора расширить**: быстрые действия (скан сети, SIEM, emergency, lock keys) — частично есть, докрутить до полного списка модулей.
- [x] **D3. Клик по уведомлению открывает соответствующее окно** (deep-link в app).

### Фаза E — Доступность и полировка
- [ ] E1. Масштабирование под высокий DPI, тёмная/светлая — уже через темы.
- [ ] E2. Анимации открытия/закрытия (есть `.w420-anim`/`.w420-min` — докрутить триггеры).
- [ ] E3. Горячие клавиши задокументированы в самом TOOLS-меню (подсказки `kb`).
- [ ] E4. Туториал при первом старте (overlay-подсказки по жестам).

## 3. Принципы
- Каждый жест — как в настоящей ОС: drag, snap, dblclick, ПКМ, Win+клавиши, Alt+Tab-подобный переключатель (Alt+Tab пока нет — добавить в фазе B!).
- Вся новая геометрия — в `STATE.win[id]` + персистентность в settings (B5), чтобы ничего не терялось.
- Темы должны влиять на ВСЁ: переменные `--fh/--fb/--glow` уже заведены; новые элементы (иконки десктопа, обои, календарь) — только через CSS-переменные, без хардкода.
- Нативный мост: fullscreen уже в Rust (`app_fullscreen_toggle`); туда же пойдут sistemные метрики трея, если понадобится частый опрос.
