# i18n (EN/ES) + панель настроек (шестерёнка)

Дата: 2026-11-04

## Что сделано

### Глобальная локализация (RU по умолчанию, EN, ES)
- `app/dist/i18n.js` — движок: словарь ключится по исходному русскому тексту; `applyLang()` обходит все текстовые узлы, `placeholder` и `title`, запоминает оригинал (`__ru`/`__ph`) и подставляет перевод. Поиск — точное совпадение или префикс (ловит интерполяции вроде «Добавлено профилей: 3»).
- **MutationObserver** повторяет проход при появлении нового DOM — поэтому локализуется и динамически сгенерированный JS-контент (bridge/sysops/voice/ai-provider) без правки их кода.
- Fallback: нет перевода — остаётся русский. `window.t('...')` — для перевода строк прямо в JS.
- `app/dist/i18n.en.js`, `app/dist/i18n.es.js` — словари по **151 ключу** (наборы ключей en/es идентичны, проверено скриптом). Покрыты: шапка, навигация, все вкладки, боковая панель, частые сообщения модулей, сама панель настроек.

### Панель настроек
- Иконка **⚙ в правом верхнем углу шапки** открывает панель (оверлей справа сверху, закрытие по клику вне/кнопкой).
- Настройки: **язык** (Русский/English/Español), **тема** (тёмная/светлая — светлая реализована через `:root[data-theme="light"]` с полной палитрой), **голос радио** (вкл/выкл), **громкость радио**, кнопка «Сбросить настройки». Применяются мгновенно, привязаны к живым контролам радио.
- **Персистентность**: Tauri-команды `settings_get`/`settings_set` (новый модуль `settings.rs`) — merge-патч в `~/.w420/settings.json`; вне Tauri фолбэк в localStorage. Настройки переживают перезапуск приложения.
