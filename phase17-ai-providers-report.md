# Этап 17 — Полный функционал управления AI-провайдерами (DONE, 2026-11-05)

## Что сделано

### Бэкенд — `app/src-tauri/src/ai_providers.rs` (+~450 строк, 12 новых команд, зарег. в `lib.rs`)
Полный цикл из UI: добавление провайдера → ключ → тест → список моделей → выбор чекбоксами → тест выбранных → сохранение → тест всех конфигураций → сортировка по скорости.

| Команда | Что делает |
|---|---|
| `ai_provider_add` | новый провайдер (имя, тип, эндпоинт; дефолтный endpoint подставляется по типу) |
| `ai_provider_add_key` | ключ шифруется AES-256-GCM в БД, наружу — только маска «…abcd» |
| `ai_provider_remove` / `ai_key_remove` | удаление провайдера (с ключами) / ключа |
| `ai_key_set_active` | вкл/выкл ключа |
| `ai_provider_set_enabled` / `ai_provider_set_default` | вкл/выкл провайдера; дефолт в `~/.w420/security_ai.json` |
| `ai_provider_test` | живой ping-чат + `GET /models`; возвращает **текст ответа провайдера**, latency, кол-во моделей |
| `ai_provider_list_models` | список моделей с эндпоинта (отсортирован) |
| `ai_provider_set_models` | сохранение выбранных моделей (чекбоксы) в конфиг провайдера |
| `ai_provider_test_models` | тест выбранных: latency + токены + **ток/с**; пишет в `model_stats` |
| `ai_provider_model_stats` | история результатов с сортировкой `name` / `latency` / `speed` |
| `ai_providers_test_all` | тест ВСЕХ провайдеров × активные ключи; пишет в `key_stats`, обновляет `avg_latency_ms`/`error_count`/`blocked_until` |

### БД — `crates/w420-ai/src/db.rs`
Таблица `model_stats` + `record_model_test()` + `list_model_stats()` (последняя запись на модель).

### UI — `app/dist/ai-provider.js`
Новая карточка «УПРАВЛЕНИЕ ПРОВАЙДЕРАМИ · ПОЛНЫЙ ЦИКЛ» во вкладке AI CORE: форма добавления провайдера (имя/тип/эндпоинт), добавление ключа, кнопки ТЕСТ ПРОВАЙДЕРА (с показом ответа модели), СПИСОК МОДЕЛЕЙ (чекбоксы), СОХРАНИТЬ ВЫБОР, ТЕСТ ВЫБРАННЫХ, сортировка статистики (по имени/задержке/скорости генерации), ТЕСТ ВСЕХ КОНФИГУРАЦИЙ, вкл/выкл, по умолчанию, удалить; у каждого ключа кнопки ВКЛ/ВЫКЛ и ✕. Ключи в браузер не приходят — только маски.
