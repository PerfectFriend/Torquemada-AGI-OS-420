# AI CORE: настоящий провайдер NVIDIA NIM + ротация 11 ключей

Дата: 2026-11-04

## Проблема
Во вкладке AI CORE список провайдеров был захардкожен (Ollama/Anthropic в localStorage) и не отражал реальную базу `~/.w420/ai_providers.db`, куда ранее засеяны NVIDIA NIM + 11 ключей из хранилища Obsidian (зашифрованы AES-256-GCM).

## Что сделано

### Бэкенд: новый модуль `app/src-tauri/src/ai_providers.rs` (4 команды)
- `ai_providers_list` — провайдеры из БД: имя, тип, эндпоинт, модели, признак default, и список ключей **только с масками** `…abcd` (последние 4 символа расшифровываются на бэкенде; сам ключ наружу не уходит), плюс статус каждого (активен, latency, ошибки, блокировка).
- `ai_providers_status` — дефолтный провайдер, стратегия ротации (FastestFirst), всего/активных ключей.
- `ai_chat(prompt, model?, provider_id?)` — **живой чат через `KeyRotation`**: все 11 ключей в пуле, автоматический перебор при ошибках/блокировках. Возвращает текст, модель, `key_mask` ключа-ответчика, `keys_tried`, токены, задержку.
- `ai_providers_test(provider_id?)` — живой тест каждого ключа (test_connection + latency), результаты с масками.
- В `w420-ai` добавлен `test_all_keys_owned()` (db-free), чтобы rusqlite Connection не пересекал `.await` (Send-требование Tauri).

### Фронтенд: `ai-provider.js`
- Список провайдеров теперь **загружается из БД** через `ai_providers_list` — там «NVIDIA NIM (default) · NVIDIA NIM · ключей: 11 · ПО УМОЛЧАНИЮ». Захардкоженные несуществующие Ollama/Anthropic убраны из дефолтного списка.
- При выборе DB-провайдера показывается карточка «КЛЮЧИ · РОТАЦИЯ»: маски ключей со статусами, строка статуса ротации, кнопки «ПРОТЕСТИРОВАТЬ КЛЮЧИ» и «ОБНОВИТЬ».
- Семплер для DB-провайдеров ходит через бэкенд-команду `ai_chat` — **ключи в браузер не попадают**. После «ПОДКЛЮЧИТЬ» показывается, каким ключом отвечено: «ключ …6PTG · попыток: 1 · N мс · модель».
- Модель по умолчанию подставляется из конфига провайдера (mistralai/mistral-large-4-1t-a52b).

## Проверка (факты)
- **Живой тест** `live_ai_chat_nvidia_rotation` (запущен с `--ignored`): `LIVE: provider=NVIDIA NIM (default) model=mistralai/mistral-large-4-1t-a52b key=…6PTG keys_tried=1 tokens=Some(151) text="ок"` — реальный ответ NVIDIA NIM через ротацию, ключ замаскирован.
- `test_providers_list_nvidia_11_keys_masked` — из БД приходит NVIDIA, **11 активных ключей**, все маски вида `…xxxx` без префикса `nvapi-`, провайдер default. ✅
- `test_mask_hides_key` — маска не содержит полный ключ. ✅
- `node --check ai-provider.js` — синтаксис ок.
- `cargo test -p w420 --lib` — 41 passed / 1 failed (старый известный `sysops::gitleaks`, к этому изменению отношения не имеет).
- `cargo build --release` — exit 0, бинарник 47.3 МБ.

## Где смотреть
Вкладка **AI CORE** → селект провайдеров (NVIDIA NIM (default), ключей: 11) → карточка ключей с масками → «ПОДКЛЮЧИТЬ» (тест «ок») или «ПРОТЕСТИРОВАТЬ КЛЮЧИ» (живой пинг всех 11).
